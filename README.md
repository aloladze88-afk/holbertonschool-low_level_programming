# holbertonschool-low_level_programming

This repository contains introductory low-level programming work in C.

It focuses on core fundamentals: how C programs are compiled with gcc, what the program entry point is (the main function), how return values work, and how to produce output using standard functions such as printf, puts, and putchar. It also covers essentials like using sizeof to inspect types and including the correct headers for standard library functions.

The aim is to build confidence writing small, correct C programs that compile cleanly with strict warnings enabled, while keeping the code clear and consistent.
